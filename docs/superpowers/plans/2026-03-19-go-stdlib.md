# Go Stdlib Refresher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a comprehensive Go standard library tab to `index.html` covering 31 packages (Go 1.21+), with ≥90% API coverage per package validated via context7 and memorable real-world snippets throughout.

**Architecture:** Single-file modification — all Go content added to the existing `index.html` as a new `<section id="go" class="lang-section">` alongside the Kotlin section. Sidebar gets a parallel `<div class="cat-list" data-lang="go">` with 31 package links. Tab-switch JS extended to toggle cat-lists and reset scroll. No new files.

**Tech Stack:** Plain HTML5, inline CSS (existing classes reused), vanilla JS (2 lines added to existing handler), context7 MCP for API validation.

**Quality bar:** Snippets must be more memorable than Kotlin docs. Prefer real call sites over toy strings. Show error handling, context propagation, and struct tags naturally where they belong.
